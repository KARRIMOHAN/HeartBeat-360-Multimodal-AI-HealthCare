# 🩺 Dr. HeartBeat — Senior AI Medical Consultant

**HeartBeat 360** official AI Medical Consultant deployed on Hugging Face Spaces.

## 🌟 Persona Features:
- **Warm & Empathetic:** Compassionate senior doctor bedside manner.
- **Evidence-Guided:** Structured clinical guidance, home-care recommendations, and red-flag symptom alerts.
- **Fast Responses:** Powered by high-speed open-source instruction-tuned LLMs (`meta-llama/Llama-3.1-8B-Instruct`).
- **HeartBeat 360 Integrated:** Connected with automated safety triage and verified doctor booking.

## 🚀 How to Deploy on Hugging Face:
1. Create a new **Space** on [huggingface.co/new-space](https://huggingface.co/new-space).
2. Select **Gradio** SDK.
3. Push or upload these files (`app.py`, `requirements.txt`, `README.md`).
4. Add your Hugging Face API key as a Secret (`HF_TOKEN`) in Space Settings.
